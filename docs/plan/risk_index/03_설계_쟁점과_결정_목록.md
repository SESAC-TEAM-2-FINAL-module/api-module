## D-7. 수온 밴드 × 오차 — **반영: B**

오차 P95 2.48℃가 밴드 폭(2·3℃)과 같은 크기라 밴드 판정이 오차 안에서 흔들린다(02 문서 쟁점 ④).

| 안 | 내용 |
| --- | --- |
| A | `value`로만 판정(v1.5 그대로). 오차는 분해 표의 입력 `lower`·`upper`로 넘겨 대시보드가 보인다 |
| **B (반영)** | `lower`~`upper` 구간으로 항목 점수의 **범위**를 내고, 지수 `lower`·`upper`에 반영 |

"추정은 점이 아니라 범위로"(v1.5 4.6.2절 그래픽 규칙 1)와 맞고, `lower`·`upper` 열의 기존 뜻("value ∓ 오차")을 지수에도 일관되게 쓸 수 있다. 대시보드도 산출을 요청했다(Q4).

| 상태 값 17종 | 늘리지 않는다 — 늘리면 CLAUDE.md 6절·4.9절 개정 |

## D-10. 이력 — **반영**

`farm_readings`에 축으로 두므로(D-3 A) 기존 `farm_reading_history`에 합산값 이력이 함께 남는다. 항목 분해는 현재값만 둔다 — 대시보드 답(Q6)과 같다.

## D-11. 단계(레벨) — **일부 반영**

v1.5 7.4절 화면 예시는 `●●●○○`(5단계로 보임)뿐이고 **단계 경계값이 없다.** 웹이 `value`를 잘라 단계를 만들면 판정을 다시 하는 것이 된다(5.5절 "대시보드는 판정을 다시 계산하지 않는다").

| 안 | 내용 |
| --- | --- |
| **A (반영)** | 모듈이 단계 코드를 넣는다 |
| B | 모듈은 경계값만 계약으로 넘기고 웹이 자른다 — 경계값을 웹이 복사하면 판정 정의가 두 곳에 생긴다 |

반영 내용:
- 경계값은 **판정 정의** `risk_index.levels`(값 `<미결>`)
- 지수 행의 `grade` 열은 **쓰지 않는다** — W 계약의 기존 의미(적조 공식 4단계)와 겹친다
- 단계 경계에 `lower`~`upper`가 걸치는지는 **모듈이 판정해 플래그로 넣는다** — 걸침 판정도 판정이다

남은 것(남은 결정 ④): 경계값, 단계 수·코드 이름(예: `VERY_LOW`~`VERY_HIGH`), 단계 코드·걸침 플래그를 담을 곳(지수 합산 표 신설 / `farm_readings`에 범용 열 `level` 추가 — DDL·계약 변경 크기 비교).

## D-12. 기여도 정의 — **일부**

**기여도 = 가중치 × 항목 점수** — v1.5 화면 예시 `+0.40`·`+0.30`·`+0.08`(= 0.15 × 0.5 = 0.075)과 같다. 화면 반올림은 대시보드 몫이고 저장 값은 반올림하지 않는다.

| 쟁점 | 선택지 |
| --- | --- |
| 제외 항목(예: 클로로필 이상값 제외)의 처리 | (가) 기여도 0으로 두고 합산 = 남은 기여도의 합 — 지수가 낮게 치우친다 / (나) 남은 항목 가중치로 재정규화 — 항목이 빠져도 0~1 척도 유지, 대신 "빠진 항목이 0점"과 구별되지 않는다 |
| 합 = `value` 보장 | (가)면 항목 기여도 합 = `value` 그대로(K5 검사). (나)면 분해 표에 정규화 전·후 기여도를 둘 다 둘지 |

제안하지 않았다 — 값의 뜻이 바뀌는 선택이다(남은 결정 ⑤). 재정규화는 금지 규칙 관련 점검 C5(grading 수온의 남은 가중치 재정규화 → 최근접 대체 효과)와 성격이 다르다(지수는 추정값이 아니다)는 점만 기록한다. 결정되면 K5를 그 정의로 고친다.

## D-13. 제외 사유 코드 — **반영**

대시보드가 문구를 붙일 코드 목록. 입력 축의 기존 값을 옮겨 새 이름을 최소로 한다:

| 코드 | 뜻 | 출처 |
| --- | --- | --- |
| `SENSOR_QUALITY` | 원천 행 품질 플래그(R1·R2 — "관측값 이상 제외") | 4.6절 플래그 |
| `INPUT_NONE` | 입력 축 `provenance = NONE` (사유는 입력 축 `none_reason`을 함께 옮김) | D-6 A |
| `NO_INPUT` | 입력 축 행 없음·`value` 없음 | grading `NO_INPUT` |

`nearby_bulletin`의 "유효 기간 안 속보 없음"은 제외가 아니라 **OK, 점수 0**(D-6)이므로 코드가 없다. 분해 표 열 이름은 `excluded_reason` *(가칭 — 계약 초안에서 확정)*.
